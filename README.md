# Muhammad Ahmad | AI/ML Engineer Portfolio

A modern, responsive portfolio website built with Next.js, React, TypeScript, and Tailwind CSS. It showcases my AI/ML projects, certifications, technical skills, and includes a working EmailJS contact form.

## Features

- Modern and responsive UI
- Built with Next.js and TypeScript
- Tailwind CSS styling
- Smooth animations
- AI/ML focused portfolio
- Project showcase with GitHub links
- Resume download
- EmailJS contact form
- Mobile-friendly design
- SEO optimized
- Fast performance

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- EmailJS
- Lucide React
